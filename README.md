# Font Smooth

**Font Smooth** is a font changer for websites by **Zema Tools**. It lets you change website fonts, text size, line height, letter spacing, and save different typography setups for different sites.

## Get Font Smooth

- [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/font-smooth/)
- [Opera Add-ons](https://addons.opera.com/en/extensions/details/font-smooth/)
- [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/font-smooth/cjlipbnnehajonaealcogpnlbedjneii)

## Features

- Included fonts and fonts installed on your device
- Custom TTF, OTF, WOFF, and WOFF2 fonts
- Text size, line height, and letter spacing controls
- Per-website typography profiles
- Reusable presets
- System, Light, and Dark themes
- Pro font roles for Body, Headings, and Code
- Backup and restore

## Font Smooth Pro

Font Smooth has a useful free tier. **Font Smooth Pro is $7.99 one-time**, with no subscription.

Pro includes unlimited website profiles and presets, up to 20 custom fonts, separate Body/Headings/Code font roles, and backup & restore.

## Privacy

Typography preferences are kept on your device. Font Smooth does not send the text you read on websites to Zema Tools.
